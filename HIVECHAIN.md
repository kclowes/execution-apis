# Regenerating chain.rlp

The test chain files (`tests/chain.rlp`, `tests/genesis.json`, etc.) are
generated by [`hivechain`][hivechain], a tool in the
[ethereum/hive](https://github.com/ethereum/hive) repository. Most contributors
do not need to regenerate the chain -- the pre-committed files are sufficient for
`make fill` and `make test`. You only need to rebuild the chain if you are adding
new block content (e.g., new transaction types, contract deployments, or fork
transitions).

## Building hivechain

```bash
git clone https://github.com/ethereum/hive.git
cd hive/cmd/hivechain
go build -o hivechain .
```

Copy the resulting `hivechain` binary into `tools/` (or add it to your PATH).

## Generating the chain

From the `tools/` directory, run `mkchain.sh`:

```bash
cd tools
./mkchain.sh
```

This runs `hivechain generate` with the parameters defined in the script and
writes output to `tools/chain/`. The generated files include:

| File             | Description                                      |
| ---------------- | ------------------------------------------------ |
| `genesis.json`   | Genesis config in go-ethereum format             |
| `chain.rlp`      | RLP-encoded sequence of blocks                   |
| `forkenv.json`   | Fork environment configuration                   |
| `headstate.json` | State dump at the chain head                     |
| `headfcu.json`   | Forkchoice update for the head block             |
| `txinfo.json`    | Index of transactions and deployed contracts     |
| `accounts.json`  | Pre-funded account keys                          |

## Updating test fixtures

After regenerating the chain, copy the new chain files into `tests/` and re-fill
the test fixtures:

```bash
# From the repo root
make fill
```

This starts a geth instance with the new chain, runs all test definitions, and
writes the `.io` fixtures to `tests/`.

## Adjusting chain parameters

Edit `tools/mkchain.sh` to change chain generation parameters:

- `-length` -- number of blocks to generate
- `-tx-count` -- transactions per block
- `-tx-interval` -- block interval between transaction batches
- `-fork-interval` -- block interval between fork activations
- `-lastfork` -- latest fork to activate (e.g., `prague`)
- `-outputs` -- comma-separated list of output files to generate

See the [hivechain documentation][hivechain] for the full set of options.

[hivechain]: https://github.com/ethereum/hive/tree/master/cmd/hivechain
